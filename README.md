# SketchPDF

Canva風のローカル専用PDFエディター。ブラウザ内だけで動作し、PDFは外部に送信されません。

## 起動

```bash
./start.sh          # ポート変更: ./start.sh 9000
```

Vite + React + TypeScript 製です。`start.sh` は `node_modules` が無ければ `npm install`、ソースが `dist/` より新しければ自動でビルドしてから、付属の簡易サーバー（`serve.py`）で `dist/` を配信します。

開発時は `npm run dev`（`127.0.0.1:5173`）でホットリロードできます。型チェック＋ビルドは `npm run build`。

待ち受けるのは **`127.0.0.1` と Tailscale のIP(100.x)だけ**です（`0.0.0.0` では待ち受けません）。
このPCでは `http://127.0.0.1:8765`、tailnet内の他の端末からは起動時に表示される `http://100.x.x.x:8765`（またはMagicDNS名）で使えます。
LANや外部ネットワークには公開されません。Tailscaleが無い環境では自動的に `127.0.0.1` のみになります。

## できること

| 分類 | 内容 |
|---|---|
| テキスト | 追加・ダブルクリックで編集・サイズ/太字/配置/文字色/背景色/不透明度（日本語対応） |
| 画像・図形 | 画像（ファイル選択・ドラッグ&ドロップ・貼り付け）、四角、円、線、矢印 |
| 手書き・注釈 | ペン、蛍光ペン（矩形）、付箋風テキスト（背景色付き） |
| ページ操作 | 並べ替え（ドラッグ）、回転、削除、複製、空白ページ挿入、PDF結合（「PDFを追加」）、分割（「選択ページを保存」） |
| 暗号化PDF | パスワード付き・編集制限付きPDFを開ける（パスワード入力ダイアログ）。保存したPDFにはパスワードは付かない |
| 編集補助 | Undo/Redo、ズーム（Ctrl+ホイール・カーソル位置を基準に拡縮）、コピー&ペースト、矢印キー微調整 |
| 表示 | サムネイルにも編集内容を反映、ページの並べ替え・削除・回転時のアニメーション |

### ショートカット

`V` 選択 / `T` テキスト / `I` 画像 / `R` 四角 / `O` 円 / `L` 線 / `A` 矢印 / `P` ペン / `H` 蛍光ペン
`Ctrl+Z` 元に戻す / `Ctrl+Shift+Z` やり直し / `Ctrl+D` 複製 / `Ctrl+C,V` コピー貼り付け / `Delete` 削除 / `Ctrl+S` 保存 / `Esc` 選択解除

## 構成

```
sketchPDF/
├── index.html                 Vite のエントリ
├── vite.config.ts
├── serve.py                   起動用サーバー（127.0.0.1 + Tailscale IP のみ、dist/ を配信）
├── start.sh                   起動スクリプト（必要なら install / build してから serve.py）
├── src/
│   ├── main.tsx / App.tsx     エントリ、全体のキー操作・ドロップ・貼り付け
│   ├── types.ts               オブジェクト・ページの型
│   ├── geom.ts                座標計算などの純粋ロジック
│   ├── docs.ts                PDF読み込み（pdf.js / qpdf 復号）・画像登録
│   ├── exportPdf.ts           PDF書き出し（pdf-lib）
│   ├── store.ts               状態（外部ストア）と全アクション、Undo/Redo
│   ├── interaction.ts         ステージ上のポインタ操作（描画・移動・リサイズ）
│   ├── hooks.ts               useFlip（並べ替えアニメーション）
│   ├── tools.ts / files.ts    ツール定義 / ファイル選択ダイアログ
│   ├── style.css
│   └── components/
│       ├── Stage.tsx          ページ一覧の表示・スクロール・ズーム
│       ├── PageView.tsx       1ページ分（PDF + オブジェクト）
│       ├── PdfCanvas.tsx      画面付近でだけPDFを描画
│       ├── ObjView.tsx        オブジェクト描画・選択枠・ハンドル
│       ├── PageList.tsx       サムネイル一覧（並べ替え・ページ操作）
│       ├── PropsPanel.tsx     プロパティパネル
│       ├── Tools.tsx          ツールバー
│       ├── TopBar.tsx         上部バー
│       └── Overlays.tsx       空状態・トースト・パスワード・ドロップ表示など
├── public/
│   ├── fonts/                 BIZ UDPGothic（表示・書き出し用の日本語フォント）
│   ├── vendor/                qpdf-wasm（復号用、初回のみ遅延読み込み）ほか
│   └── legacy/                移行前の素のHTML/JS版（動作比較用、確認後に削除予定）
└── docs/                      作業ドキュメント
```
